# OLYMPUS

A hard science-fiction soldier's life for the browser. You are a career Martian marine: barracks, mess hall, drills and the range on Mars under 0.38 g; drop ships, months-long transits under thrust, peacekeeping on Europa, ship combat and boarding seen from inside a strapped-in body, and special operations later. High-resolution pixel art, top-down at several scales, realism where it makes the game better.

In design: the plan and the first playable are on their way. See `docs/` as it fills in.
